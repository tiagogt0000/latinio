# Latinio

[Latinio öffnen](https://tiagogt0000.github.io/latinio/)

Dieses Repository enthält die öffentliche Anmeldung und die Startdateien der installierbaren App. Du erhältst deinen persönlichen Zugangscode vom Administrator.

Die Anwendung und ihre Daten werden nach erfolgreicher Anmeldung vom privaten Server geladen. Bereits freigeschaltete Geräte können gespeicherte Inhalte auch offline verwenden.
